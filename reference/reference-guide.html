Reference guide: extraction logic for the expanded cluster.

Forty additional references (41–80) added to the cluster. This doc is the extraction key — what each image contributes, what to use, what to skip. Paired with README.md, which covers refs 01–40 and establishes the two-register taxonomy. Read the README first; this document extends it without restating it.

The core rule across this cluster: not every image is an endorsement of its whole. Several of the most useful references contribute one specific move — a font, a palette, an issue-cover structure — while the rest of the image is off-register and should be ignored. The extraction and structural tags below mark those cases explicitly.

00 · how to read this guide

Four tags. Each ref carries exactly one.

classification

Every reference 41–80 is classified as one of the four below. The classification determines how to use the image. Read the tag before the description.

in register
Whole image on-register. Use as a direct compositional reference for the relevant format.
extraction
Only one element is useful — a font, a palette, a single move. Rest of image is off-register. Strict extraction only.
structural
Visual execution is off-register but the structural logic (how the piece is organized) is directly useful. Reuse the structure, not the style.
negative ref
Included as a counter-example. Marks what Marginalia is consciously not doing. Do not extract anything.

03 · cross-cutting patterns

What the expanded cluster adds to the system.

read holistically

Five distinctions this batch makes that the original 40 did not fully articulate. Each is a real addition — not a restatement.

  • palette extension
    A softer, dustier secondary palette emerges across the new references — butter-cream, dusty sage, periwinkle, soft blush, cornflower — all adjacent to the locked cream/navy/lavender but pushing into more muted warm neutrals. These are candidate seasonal accent swatches, not replacements. refs 49 · 73 · 47 · 58 · 68
  • typography extension
    Two specific display-type candidates: a bubbled outline hand-display face for rare hero moments (ref 45 extraction only), and typewriter-mono as small caption grammar now confirmed across several references. General Sans remains the primary, IBM Plex Mono the secondary — these extensions expand the acceptable hero-display register slightly. refs 45 · 64 · plus existing 24, 28, 30
  • handwriting-in-the-world
    Handwriting that exists inside the image rather than added over the top — written into grass, on crumpled paper picked up and photographed, on a postcard verso, on a preprinted diary page. This is a sharper version of the epistolary register and resolves some of the earlier ambiguity about when handwriting is permitted. refs 50 · 60 · 65 · 66 · 67
  • issue-cover structure
    Two strong structural precedents for a monthly or annual publication cover (69, 79). Both reject their own visual execution but offer directly adaptable organizational logic. The Marginalia cover template can be built by combining their structures with the locked system visuals. refs 69 · 79 · plus extension of existing 31
  • register sharpening
    The new batch narrows the system rather than expanding it. Ref 76 specifically re-classifies a previously permissive entry (existing 34) as a negative reference. Several other entries emphasize restraint at the expense of density. The direction of travel is clear: quieter. refs 53 · 54 · 55 · 56 · 70 · 74 · 76

06 · if uploading to claude design

What to include, what to hold back.

extraction hygiene
extraction hygiene
Upload the in-register entries first. Hold the extraction and structural entries back until the baseline is extracting correctly.

Claude Design averages across what it's shown. If the extraction references are uploaded alongside the in-register ones without annotation, the tool will extract the whole image rather than the single element that matters — and the busy / decorative / saturated portions of those images will pollute the style profile.

Recommended upload order. Batch 1: the twelve clear in-register additions (41, 42, 43, 44, 46, 50, 51, 52, 53, 54, 55, 56, 57, 58, 60, 62, 65, 66, 67, 68, 71, 72, 74 — twenty-three entries in total, the spine of the cluster). Verify Claude Design's extraction is reading these correctly. Only then add the extraction and structural entries (45, 47, 48, 49, 59, 61, 63, 64, 69, 73, 75, 78, 79, 80) — with the annotations from this guide pasted alongside each image upload. Never add ref 76 (the negative reference) to Claude Design.

If the tool's extraction starts producing busy collage, cozy lifestyle, serif display, scattered doodles, or over-saturated color, remove the extraction and structural entries and re-extract from the in-register spine only.
