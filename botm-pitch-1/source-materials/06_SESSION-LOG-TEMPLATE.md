# SESSION LOG TEMPLATE — Found Document Project
*Copy this into a new Google Doc on day one. Title it "Found Document — Session Log." Update at the end of every session, even if the session was 10 minutes. The log is the single source of truth for where you are. Without it, every new session has to rebuild context from scratch — which is the exact friction this scaffold exists to remove.*

---

## HOW TO USE

- One entry per session (any session that touched the project)
- Add new entries to the TOP, so most recent is always visible first
- Each entry has the same five fields. Fill what you can. Skip what you can't.
- Don't editorialize. Don't apologize for a short session. The log is for handoff, not performance.
- Reread the previous entry before you start a new session — that's the resume protocol

## DORMANCY PROTOCOL

If 14+ days have passed since the last entry, the project is dormant. That is information, not failure.

When you return:

1. Read the most recent three entries (not just the most recent one — context cools)
2. Open `01_PROJECT-PLAN.md` and find the next single move
3. Ask one honest question: *Am I picking this up, or am I checking on it?*
   - Picking up: do the next single move. Even if it's small. Even if it's just opening the doc.
   - Checking on it: that is also valid. Log the check. Close. Walk away.
4. Do not re-plan. The plan exists. Trust it.

If 60+ days dormant, do a deliberate check-in: is this still the project, or has it become something to park / let go / fold into something else? Decide. Log the decision.

---

## IF YOU GET STUCK MID-PHASE

Symptoms: avoiding the doc, opening it and closing it, doing "research" instead of writing, planning instead of doing.

Move:

1. Look at the current open box. Is it too big? If yes — break it smaller in the log: *"the actual next move is opening the Google Doc and writing one sentence"*
2. Set a 10-minute timer. Do that smaller move. Stop.
3. Log it. Even if all you did was open the doc.
4. The friction is the work. Don't comment on the friction.
