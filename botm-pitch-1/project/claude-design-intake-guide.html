Claude Design intake — field-by-field guide.

Step-by-step instructions for completing the Claude Design "Tell us about your company" intake form. Each field below corresponds to a field in the actual form. Copy-paste ready text is provided for the text fields.

the form · field by field

Six fields, in order.

field1
Company name and blurb
(or name of design system)
paste

Since the project name has not been finalized, name the design system after yourself. This becomes the umbrella brand identity that future projects can inherit from.

copy and paste this into the field:
Mia Jones — Visual Language A visual language for slow, considered editorial work. Cream paper, quiet typography, real photography treated and placed with restraint, white space treated as composition. The aesthetic of small literary monographs and editorial restraint.
field2
Link code on GitHub
URL field
skip

Skip this field. There is no public GitHub repository for the visual language. The HTML files contain everything Claude Design needs.

field3
Link code from your computer
drag a folder here or browse
upload

This is the most important upload. Drag the mia-visual-language folder you created in prep step 1 into this field. Claude Design will read the four HTML files — including their CSS variables, font imports, component classes, and rendered structure.

The form note says "Claude will copy selected files" — that's fine. The four HTML files are self-contained and don't depend on external assets beyond the font imports.

why HTML works as "code" here

The HTML files contain CSS variable declarations (colors, typography, spacing tokens), @import statements for fonts, and rendered visual examples of the system in use. Claude Design extracts patterns from this exactly the way it would from a React component library — by reading the code and the rendered structure together. The visual language foundation document is intentionally built to be machine-readable as a design system specification.

field5
Add fonts, logos and assets
drag files here or browse
optional

Fonts: Skip. General Sans is hosted on Fontshare and IBM Plex Mono and Reenie Beanie are hosted on Google Fonts — they're imported via URL in the HTML files and Claude Design will resolve them automatically. No font files need to be uploaded.

Logos: Skip. There is no logo or wordmark yet — the project name has not been finalized. The visual language is intentionally identity-mark-free at this stage.

Reference assets — recommended optional addition: The Claude Design help article specifically says "Include real examples, not just specs. A finished landing page or marketing site tells Claude more about your brand's feel than a color palette alone." Consider uploading 5–10 of the inspiration screenshots from your refs folder — the Earth Era cover, the Beuys spread, the chapbook examples, the pressed plant herbarium pages. These give Claude Design additional finished examples in the visual register.

If you upload reference images, choose ones that demonstrate the quiet chapbook restraint — not the busy collage layouts. Recommended priorities:

  1. The "Echter Arznei-Baldrian" pressed plant spread
  2. The "Earth Era" cover with the dark green leaf
  3. The "Beuys in Kleve" spread with three small photos and dense text column
  4. The "iterations" landscape thumbnails on cream
  5. The "Chloe Benjamin" homepage with sparse small images
  6. The "Listening for Silence" spread with grayscale forest image and quiet right-page text
  7. The "Birch Tree" book spread with type and small photo
  8. The Lots Sheppard duotone landscape pair
field6
Any other notes?
free-text field
paste

This is where you give Claude Design explicit guidance on what to pay attention to and what to avoid. Use this field aggressively — it acts as the prompt that frames how Claude Design interprets the uploaded files.

copy and paste this into the field:
Visual language summary Cream ground (#FAF6ED) — never pure white. Ink type (#1C1C1A) — never pure black. Dusty navy (#3E4A66) as second voice. Soft lavender (#A89DBD) as accent — used at most once per artifact. Three faces: General Sans (Fontshare, primary), IBM Plex Mono (metadata/captions), Reenie Beanie (handwriting — used exactly once per artifact, for closing signature only). Critical rules — non-negotiable
  • No serifs. Ever.
  • No pure black or pure white.
  • Real photography, treated to halftone or duotone, placed at modest scale on cream.
  • No collage with tape, rotation, or overlap. Images are placed, not stacked.
  • White space is the design — generous margins, single-image-per-page restraint.
  • Hand element used exactly once per artifact.
  • Lavender used at most once per artifact.
  • No forest green as primary (only inside duotone-treated photography).
Register — what to read as, what to avoid Intellectually serious, humanly warm. Direct, considered, with breath. Reads as small literary monograph or editorial chapbook — not as product, not as lifestyle. Avoid: cozy, Kinfolk, flatlay, feminine-domestic-coded, "in today's world" openers, motivational language, performed enthusiasm. Voice vocabulary Use "reader" not "user." Use "work" not "content." Use "writer/director" not "creator." Name authors and books specifically. Use roman numerals for sections (i., ii., iii.). Use em dashes with spaces (— like this —). Primary reference The file visual-language-foundation.html demonstrates the system by being the system. It contains the complete brand bible — color palette as actual swatches at scale, typography specimens at real sizes, layout examples as finished compositions, voice samples in the system's own voice. Extract from this file as the primary source. Supporting examples The other three HTML files show finished applications:
  • botm-deck-mockups.html — five-slide pitch deck (digital editorial, 16:9)
  • marginalia-zine-brief.html — eight-spread zine production brief (print editorial)
  • botm-design-system.html — code/token reference document
No wordmark yet The publication name is being finalized. The visual language exists independent of any wordmark. The "M." monogram appearing inside lavender postage stamps is one-off use specific to current pitch work — not a standalone brand mark. Do not extract a logo or treat the M. as an identity element.

paste the entire block above (including the headings and lists) into the "Any other notes?" field

after submitting

What to do once Claude Design extracts.

stepA
Wait for the extraction.
automatic, takes a few minutes
wait

Claude Design will analyze the uploaded folder and the notes, and generate a UI kit — color palette, typography specifications, components, layout patterns. This typically takes a few minutes.

stepB
Validate with a test project.
before publishing
test

Before publishing the system to your team (or to your default), create a test project. Use one of these prompts to verify the extraction matches your visual register:

  1. "Design a one-sheet for a film about the interior life of reading."
  2. "Create an Instagram carousel introducing a new long-form essay project."
  3. "Make a Substack header and intro post in this visual language."
  4. "Build a landing page for a small literary publication."

If the output reads cream-grounded, type-set-with-care, generous-margin, single-image-per-page — the extraction worked. If it reads as generic, busy, or off-brand, see troubleshooting below.

stepC
Publish.
switch the toggle on
publish

Once the test project output reads correctly, switch the "Published" toggle on. After publishing, any project created from the Claude Design homescreen will use this visual language by default.

troubleshooting

If extraction comes out wrong.

Claude Design extracts inductively. If it gets the wrong system, the fix is more or different examples plus stronger guidance in the notes field.

ifA
Output uses serifs, full-color photography, or pure white.
re-prompt

The system was extracted incorrectly. Open Claude Design's "Remix" interface for the system and prompt: "Re-read the visual-language-foundation.html file, especially Section II (Typography) and Section VII (Do/Do not). The system uses no serifs, no pure black or white, and no full-color photography. All photography is halftone or duotone. Update the design system accordingly."

ifB
Output reads as busy or collage-heavy.
re-prompt

Claude Design extracted "collage" instead of "restraint." Prompt: "The visual language is editorial restraint, not busy collage. White space is the design. Single image per page at modest scale, surrounded by generous cream margin. Re-read Section III (Composition principles) and Section V (Layout examples) of the foundation."

ifC
Output reads as cozy, lifestyle, or feminine-domestic.
re-prompt

The voice register did not transfer. Prompt: "The register is intellectually serious and humanly warm — not lifestyle, not cozy, not Kinfolk. Read the voice anchor paragraph in Section VI of the foundation. The work reads as a small literary monograph, not as a lifestyle product."

ifD
Output keeps adding handwritten elements everywhere.
re-prompt

The "hand element used once" rule did not transfer. Prompt: "Reenie Beanie is used exactly once per artifact, only for the closing signature. Never for marginalia annotations, scattered hand notes, or curved arrows. See Section III principle v. and Section IV material m.07."

future · when project name is locked

Adding the wordmark layer later.

when·
Update Section VIII of the foundation.
remix the system in Claude Design
update

When the publication name is decided, Section VIII (Wordmark) of the foundation document gets built — logotype in General Sans 500, monogram variants, clear-space rules, minimum-size specifications, color variants for cream / ink / navy backgrounds.

From your Claude Design organization settings, click "Open" next to your design system. Click "Remix" in the upper right to open the chat. Upload the updated foundation document and prompt: "This is the updated visual language foundation with the wordmark added in Section VIII. Update the design system to include the new identity layer."
